# Leela Townsley

I'm a software engineer in Los Angeles working in C++, Python and Linux. I like real-time systems, simulation and concurrency, and I'm looking for early-career roles in aerospace and simulation, cloud gaming and media infrastructure.

My background is unusual: I worked in TV and film development (Netflix's The Sandman, Starz's American Gods, Amazon's Good Omens), then moved into computer science through a second B.S. at Oregon State and a developer internship at Xsolla, where I built Unreal Engine experiences and automated builds and testing on AWS.

## What I'm working on

- A C++ binary packet encoder and parser (header, sequence number, timestamp, payload, CRC-16) that rejects corrupted packets cleanly. In progress.
- A C++ log parser that counts and skips bad lines in a one-million-line session log. In progress.
- Low-level networking and concurrency in C++ (epoll servers, a UDP latency probe, a lock-free ring buffer) and a mini cloud game streamer with latency measurements. Planned.
